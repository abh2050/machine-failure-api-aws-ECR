02 / ENGINEERING JUDGMENT

Correctness lives
at the boundaries.

The core work is translating a fitted estimator into a reproducible service—with measurable behavior and explicit failure modes.

A / FEATURE CONTRACT

One transform, two execution contexts.

Training and inference import the same NumPy-only feature module. Six inputs become nine ordered float32 features, including power, temperature delta, and torque × wear. Startup checks metadata against FEATURE_ORDER to catch incompatible artifacts.

Inspect features.py ↗
B / NUMERICAL INTEGRITY

Export is a tested boundary.

ONNX keeps pandas and scikit-learn out of the serving image. The training script asserts a maximum absolute probability error below 10−3 on the held-out test partition. The recorded difference is 1.16 × 10−7.

Inspect the export gate ↗
C / DECISION POLICY

Optimize for missed-failure risk.

The validation set determines the highest threshold satisfying recall ≥ 0.90. At the resulting threshold of 0.053647, test recall is 0.9216 and precision is 0.6026. This makes the false-alarm tradeoff explicit; the score is not established as a calibrated risk estimate.

Inspect model metadata ↗
D / REPRODUCIBLE DELIVERY

The deployed artifact is identifiable.

Build-input hashes determine immutable ECR tags; Lambda references the image digest. Model and metadata travel together. Resource checks and conditional updates avoid unnecessary rebuilds and warm-environment recycling.

05 / OPERATING ENVELOPE

Known limits. Clear next steps.

Access & operations

The current API is public with a 10 requests/s stage throttle and burst 20. Authentication, access logging, alerting, and stronger deployment automation are natural next steps.

Model lifecycle

Training is script-driven; deployment bundles a fixed model. Automated retraining, drift detection, calibration checks, and site-level validation remain future work.

Failure evidence

The build log records invalid-input rejection, missing invoke permission, and feature-order mismatch drills. Each tests a different boundary in the serving stack.
